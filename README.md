# UPI Fraud Detection Using Machine Learning

## Overview

The UPI Fraud Detection System is a machine learning-based application developed to identify fraudulent UPI transactions by analyzing transaction-related patterns and message content. The system uses the Random Forest algorithm to classify transactions as legitimate or fraudulent, helping improve digital payment security and fraud prevention.

## Objective

The main objective of this project is to detect suspicious UPI transactions automatically using machine learning techniques. The project aims to reduce fraudulent activities in digital payment systems by analyzing transaction data and identifying abnormal patterns.

## Features

* Fraud detection using Machine Learning
* Random Forest classification model
* Transaction message analysis
* Real-time prediction capability
* User-friendly web interface for transaction checking
* Dataset preprocessing and feature extraction
* Improved fraud identification accuracy

## Technologies Used

* Python
* HTML
* CSS
* Flask
* Scikit-learn
* Pandas
* NumPy

## Working of the System

1. The system collects transaction-related data and messages.
2. Data preprocessing and cleaning are performed on the dataset.
3. Important features are extracted using TF-IDF vectorization.
4. The Random Forest algorithm is trained using labeled transaction data.
5. When a user enters transaction details or messages, the model predicts whether the transaction is legitimate or fraudulent.
6. The result is displayed through the web interface.

## Machine Learning Implementation

The project uses the Random Forest classification algorithm because of its high accuracy and reliability in handling classification problems. TF-IDF vectorization is used to convert transaction messages into numerical features for model training and prediction.

## Outcome

The project successfully demonstrates the use of machine learning techniques for fraud detection in digital payment systems. It provides practical exposure to data preprocessing, model training, prediction systems, and web integration using Python and Flask.
